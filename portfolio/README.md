# Portfolio

This directory will contain public, reproducible deliverables from completed agent-to-agent tasks.

## Suggested Structure

```text
portfolio/
└── task-001-short-name/
    ├── README.md
    ├── deliverable/
    ├── validation/
    └── sources.md
```

Each task should include:

- requirements and success criteria;
- implementation summary;
- files generated or changed;
- commands used for validation;
- observed results;
- limitations and follow-up actions.

Do not place secrets, private keys, access tokens or personal data in this directory.
